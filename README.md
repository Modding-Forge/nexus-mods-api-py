# nexusmods-api

Unofficial, typed synchronous and asynchronous Python clients for the Nexus
Mods REST v1, GraphQL v2, and REST v3 APIs.

The package supports manual application-specific API keys, Nexus Mods
WebSocket SSO, and OAuth 2.0 Authorization Code with PKCE.

Authoritative documentation is maintained as AsciiDoc in
[`docs/modules/ROOT/pages/index.adoc`](docs/modules/ROOT/pages/index.adoc).

The current development release is `1.0.0rc1`. Python 3.12 or newer is
required. Install `nexusmods-api[sso]` for the optional WebSocket SSO flow.
