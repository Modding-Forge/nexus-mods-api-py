= REST v3 code generation

The pinned OpenAPI snapshot and its SHA-256 file live under `specs/`. Regenerate offline:

[source,shell]
----
uv run python tools/generate_v3.py
----

Only after reviewing an upstream specification change, update the expected hash in the
generator and run `--update-spec`. Review the snapshot and generated diff together. Never
edit files under `src/nexusmods_api/v3/generated/` manually. CI regenerates offline and
requires an empty diff.

== Python API reference generation

The Antora `reference` module is generated from runtime signatures, type hints,
Pydantic field metadata, and parsed Google-style docstrings. The locked
`pypandoc-binary` development dependency supplies Pandoc, which converts embedded
GitHub-flavored Markdown to AsciiDoc. Regenerate the reference after changing a
public API or its documentation:

[source,shell]
----
uv run python tools/generate_api_reference.py
----

Generated pages and navigation are checked in. Verify that they are current without
writing files:

[source,shell]
----
uv run python tools/generate_api_reference.py --check
----

Do not edit files under `docs/modules/reference/` manually. Improve the Python source
documentation or the generator instead.
