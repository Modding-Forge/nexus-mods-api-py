link:https://github.com/Modding-Forge/nexus-mods-api-py/blob/master/src/nexusmods_api/v1/models/mod.py#L8[Source]

Describes Nexus Mods REST v1 mod metadata.

.Fields
[cols="1,1,1",options="header"]
|===
|Name |Type |Description
|author |str \| None |The mod author name, when reported.
|available |bool \| None |Whether the mod is currently available, when reported.
|category_id |int |The identifier of the mod's category.
|contains_adult_content |bool |Whether Nexus Mods marks the mod as adult content.
|created_timestamp |int \| None |The mod's Unix creation timestamp, when reported.
|description |str \| None |The mod's full description, when reported.
|domain_name |str |The Nexus Mods game domain containing the mod.
|endorsement_count |int \| None |The number of user endorsements, when reported.
|game_id |int |The numeric Nexus Mods game identifier.
|mod_downloads |int \| None |The mod's total download count, when reported.
|mod_id |int |The mod identifier within its game domain.
|mod_unique_downloads |int \| None |The mod's unique download count, when reported.
|name |str \| None |The mod's display name, when reported.
|picture_url |str \| None |The mod's primary image URL, when available.
|status |str \| None |The mod's publication status, when reported.
|summary |str \| None |The mod's short summary, when reported.
|uid |int \| None |The globally unique Nexus Mods entity identifier, when reported.
|updated_timestamp |int \| None |The mod's Unix update timestamp, when reported.
|uploaded_by |str \| None |The uploader's display name, when reported.
|uploaded_users_profile_url |str \| None |The uploader's profile URL, when reported.
|version |str \| None |The current mod version, when reported.
|===

.Fields
[cols="1,1,1",options="header"]
|===

|content_preview_link |str \| None |The endpoint for previewing archive contents, when available.
|description |str \| None |The file's description, when supplied.
|external_virus_scan_url |str \| None |The external virus-scan result URL, when available.
|file_id |int |The file identifier within its mod.
|file_name |str \| None |The stored file name, when reported.
|id |list[int] \| None |The composite legacy identifiers returned by some v1 endpoints.
|is_primary |bool \| None |Whether the file is the mod's primary download, when reported.
|mod_version |str \| None |The associated mod version, when reported.
|name |str |The file's display name.
|size |int \| None |The file size in bytes, when reported.
|size_kb |int \| None |The file size in kibibytes, when reported.
|uid |int \| None |The globally unique Nexus Mods entity identifier, when reported.
|uploaded_time |str \| None |The file's formatted upload time, when reported.
|uploaded_timestamp |int \| None |The file's Unix upload timestamp, when reported.
|version |str \| None |The file version, when reported.
|===
