= Installation

The library requires Python 3.11 or newer.

[source,shell]
----
python -m pip install nexus-mods-api
----

The base package contains all HTTP APIs, manual API-key authentication, and OAuth.
Install WebSocket SSO explicitly:

[source,shell]
----
python -m pip install "nexus-mods-api[sso]"
----

`nexus-mods-api[all]` currently selects the same optional SSO capability and is intended
for applications that want every supported feature.
