= GraphQL v2

The GraphQL clients accept arbitrary documents with a caller-selected Pydantic-compatible
response type. Convenience methods cover games, mods, mod search, files, collections,
revisions, and users.

`get_mod` and `get_mod_files` accept the decimal 64-bit Nexus Mods mod UID returned by
GraphQL. Collection revisions are addressed by collection slug and revision number because
the current upstream schema no longer accepts a standalone revision ID. Pass
`game_domain` when a collection slug needs to be disambiguated.

[source,python]
----
mod = client.get_mod("7318624383875")
revision = client.get_revision(
    "rqhcxy",
    1,
    game_domain="skyrimspecialedition",
)
----

By default, GraphQL errors raise `NexusGraphQLError`. Set `allow_partial=True` to validate
and return data accompanied by errors, then inspect `last_errors`. Use `execute_raw` when
the complete raw envelope is required.
