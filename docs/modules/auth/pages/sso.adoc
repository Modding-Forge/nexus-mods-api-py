= WebSocket SSO

Install the `sso` extra, configure the application slug assigned by Nexus Mods, and keep
the generated WebSocket session open while the user authorizes in a browser.

[source,python]
----
include::example$sso.py[]
----

The library uses Nexus Mods SSO protocol 2, validates the initial connection token,
and includes the registered application slug in the browser authorization URL. It
sends WebSocket pings, enforces timeouts, validates structured responses, and returns
`ApiKeyAuth`. It does not persist the connection token or issued key. Both `SSOFlow`
and `AsyncSSOFlow` are available from `nexusmods_api.sso`.
