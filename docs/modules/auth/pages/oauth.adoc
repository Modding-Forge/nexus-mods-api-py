= OAuth PKCE

OAuth uses Authorization Code with an RFC 7636 S256 PKCE challenge and a cryptographically
random state value. Supply the client ID and redirect URI registered for your own Nexus
Mods OAuth application.

For headless applications, display `authorization.authorization_url`, receive the callback
through your own mechanism, and pass the full callback URL to `exchange_callback`. For a
desktop browser flow, `OAuthLoopbackFlow` and `AsyncOAuthLoopbackFlow` bind only to IPv4
loopback and validate state before exchanging the code.

`OAuthAuth` and `AsyncOAuthAuth` provide proactive refresh, one refresh after HTTP 401, and
coalescing so concurrent failures for the same token perform only one rotation.
